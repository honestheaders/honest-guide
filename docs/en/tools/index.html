Free tools

Small tools that run only in your browser. Nothing you type is sent anywhere.

  • CSP builder (Report-Only first, then enforce)List where your scripts, styles and images come from, or click a bookmark on your own page to fill it in. Get a Report-Only header to test first, then the enforcing one, for nginx, Apache and PHP.
  • Mixed content finder (http:// on an HTTPS page)Click a bookmark on your own page, or paste its HTML. See every http:// address, which ones browsers block, and the https:// versions to copy.
  • PHP version checker (CVE-2026-109618/109619)Paste php -v or an X-Powered-By header. See if your PHP is at or above the 21 October 2026 fixed release for its branch, and which interim settings php.ini has.
  • Security headers checker (paste your headers)Paste response headers from DevTools or curl. See which of the 7 recommended security headers are missing and which 5 old headers to remove.
  • Set-Cookie builder and checkerBuild a Set-Cookie header with Secure, HttpOnly, SameSite, Partitioned and prefixes, and see which combinations browsers reject.
  • Cookie JSON to cookies.txt converter (both ways)Paste a cookie editor's JSON export and get a Netscape cookies.txt for curl or wget, or turn a cookies.txt back into JSON. Runs only in your browser.
  • XPath tester (paste HTML, see what matches)Paste some HTML and an XPath expression. See the match count, the text of each match, and copy the results, one per line.

Practical notes on HTTP headers, cookies and browser tools, by Honest Tools. Facts are checked against official documentation; each article lists its sources and the date they were checked.
