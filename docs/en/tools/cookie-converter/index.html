Cookie JSON to cookies.txt converter

HOW IT WORKS

Paste a JSON list of cookies (the property names Chrome's chrome.cookies API uses, which many cookie editors export) to get a cookies.txt file with the seven TAB-separated fields curl expects. Or paste a cookies.txt to get JSON back. It runs only in your browser: nothing you paste is sent anywhere.

    The mapping it uses

    cookies.txt fieldJSON property
    Domain (with #HttpOnly_ in front when HttpOnly)domain, httpOnly
    Include subdomains (TRUE/FALSE)the opposite of hostOnly (our reading)
    Pathpath
    HTTPS only (TRUE/FALSE)secure
    Expiry (seconds since 1970, or 0)expirationDate; 0 when it is missing (session cookie)
    Name, valuename, value

    The reasons, and a Python version of the same converter: Cookie editor export to cookies.txt: the 7 fields curl expects. Try the result with curl -v -b cookies.txt https://your-test-site.example/.

    Who this is not for

    • cookies.txt has no place for SameSite or partition keys, so converting to cookies.txt drops them, and converting back cannot restore them.
    • If your export uses other property names, the converter tells you which are missing instead of guessing.
    • The files hold live session values. Keep them out of Git and bug reports, and delete them after testing. Only use cookies for sites you are allowed to test.
