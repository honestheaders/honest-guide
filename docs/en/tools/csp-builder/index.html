CSP builder

SHORT ANSWER

List where your page loads scripts, styles, images, fonts and API calls from, and this builder writes a Content-Security-Policy-Report-Only header to test first and the enforcing Content-Security-Policy header for later, with lines for nginx, Apache and PHP. A bookmark can fill in the list from a page of your own site. It runs only in your browser.

Fill it in from your own page

  1. On a computer, drag this link to your bookmarks bar: Collect my sources
  2. Open a page of your site, use it for a moment (menus, forms, anything that loads more), then click the bookmark. It lists the origins that page loaded from and counts inline scripts and styles, then opens this builder with them. The list travels after the #, which browsers do not send to any server.

Sources for each kind (separate with spaces; same-site files are 'self'). Anything left as only 'self' falls back to default-src 'self'. An empty box becomes 'none'.

The order to roll it out

  1. Send the Report-Only header. Nothing is blocked; violations are reported. MDN says the report-to directive must be there for reports to be sent, so add a report address.
  2. Fix what the reports show: move inline scripts and onclick-style handlers into files, or add the missing origin.
  3. Send the enforcing Content-Security-Policy header. You can keep the Report-Only one next to it while you try a stricter version; browsers honor both.

More detail: Content-Security-Policy Report-Only: the safe way to send your first CSP.

What the bookmark cannot see

  • Only what that one page loaded so far. Other pages, logged-in areas and rarely used buttons may load more, so collect on several pages and merge the lists.
  • A font or image loaded from CSS is sorted by its file name, so check the font and image boxes.
  • It does not read your server's current headers. For those, use the security headers checker.

Who this is not for

  • Sites that already use per-response nonces or hashes ('nonce-…', 'strict-dynamic'). This builder writes an allowlist of origins, which is easier to start with but looser than MDN's nonce-based strict CSP.
  • Anyone who needs a policy on a page they do not control. A CSP is set by the site that sends the page.
