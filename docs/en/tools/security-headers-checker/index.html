Security headers checker

HOW IT WORKS

Paste the response headers of one page. The checker looks for the 7 headers we recommend adding and the 5 we recommend removing, and says what to change. It runs only in your browser: nothing you paste is sent anywhere.

Where to copy the headers from

  • Chrome DevTools: Network panel, reload, click the first (document) request, then in Response Headers turn on Raw and copy.
  • Command line: curl -sI https://your-site.example prints only the headers.

What each header does, and example values: Security headers checklist: the 7 to add and the 5 to remove.

Who this is not for

  • This only looks at whether headers are present and at a few obvious values. It does not judge whether your Content-Security-Policy is strict enough, and it is not a security audit.
  • If you want a site scanned from the internet by URL, Mozilla's HTTP Observatory does that.
