坪・平米・畳の換算ツール

広さの単位を、まとめて換算します。どれか1つに数字を入れてください。

1坪=約3.3058㎡。畳は、不動産の広告で使われる目安(1畳=1.62㎡)で計算しています。地域や建物によって畳の大きさは違います。

広さを測る道具

部屋の広さを自分で測るときに使う道具です。
