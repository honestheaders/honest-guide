引っ越しの役所手続きはいつまで?転出届・転入届・マイナンバーカードの期限

更新日:2026-09-30

※この記事にはプロモーション(広告)が含まれます。商品リンクから購入されると、当サイトに報酬が入ることがあります。

※ この記事は一般的な制度の説明で、個別の相談に代わるものではありません。個別の事情(海外転出、世帯分離、外国籍の方など)は、住民票のある市区町村の窓口や、各制度の問い合わせ窓口にご相談ください。

自分の日付で期限を出したい人は → 期限計算ツール(無料)。日付を入れると期限日と残り日数が出て、カレンダーに入れたり家族にLINEで送ったりできます。

引っ越しの荷造りに追われていると、役所の手続きの期限を見落としやすくなります。ここでは「どの手続きに、いつまでという期限があるか」だけを、先に並べます。

期限の早見表

手続き 期限・時期 出典
転出届 引っ越す前に届け出る(事前の届出が原則) 総務省資料
転入届(別の市区町村へ引っ越したとき) 新しい住所に住み始めた日から14日以内 総務省資料、マイナポータル
転居届(同じ市区町村内で引っ越したとき) 引っ越した日から14日以内 総務省資料、マイナポータル
マイナンバーカードの継続利用手続き 転入届の提出後90日以内 マイナポータル
自動車の住所変更(変更登録) 期限あり。国土交通省のポータルで確認 国土交通省

転出届:引っ越す前に出すのが原則

総務省の資料では、転出する人は「あらかじめ」市区町村長に届け出ることとされています。急に引っ越しが決まり、旧住所の窓口へ行く時間がない場合は、郵送での届出も認められています。

マイナンバーカードを持っている人は、マイナポータルからオンラインで転出届を出せる市区町村があります。東京都新宿区の案内では、引っ越し予定日の30日前から申請でき、引っ越し後は10日以内という条件が示されています。この日数は自治体ごとに異なる場合があるため、お住まいの市区町村のページで確認してください。

転入届・転居届:14日以内

新しい住所に住み始めたら、14日以内に転入届(同じ市区町村内なら転居届)を出します。マイナポータルの案内では、14日以内に手続きをしないと、マイナンバーカードは失効すると書かれています。

マイナンバーカードを使って転出届を出した場合は、転入時にカードを持参します。新宿区の案内では、同一世帯全員分のカードを持参すること、印鑑登録を同じ日にしたい場合は印鑑を持参することが示されています。必要なものは自治体で異なるため、事前の確認をおすすめします。

マイナンバーカード:転入後90日以内の継続利用手続き

別の市区町村へ転入した場合は、転入届の提出後90日以内にマイナンバーカードの継続利用手続きが必要です(マイナポータルの案内による)。同じ市区町村内の転居では、カードの住所変更手続きを行います。手続きの窓口や方法は自治体で異なるため、転入先の市区町村の案内で確認してください。

自動車を持っている場合

国土交通省の自動車検査登録総合ポータルサイトには、引っ越しをしたとき、法令で定められた期限内に住所変更の手続き(変更登録)が必要と書かれています。手続き先は各運輸支局・事務所で、受付は平日のみです。新しい住所を確認する書類として、住民票などの提出が求められます。期限の日数は、同ポータルの最新の案内でご確認ください。

手続きに実際に必要になる物

引っ越し作業そのものには段ボールが、役所の手続きには、受け取った書類をまとめるクリアファイルなどが役に立ちます。

  • 楽天市場「引っ越し 段ボール」を探す›
  • 楽天市場「クリアファイル A4」を探す›

注意点として、どちらも商品によって厚みや大きさが違うため、荷物の量や書類のサイズを測ってから選ぶ必要があります。また、この記事は商品を使った感想ではなく、公的情報の整理です。

期限を管理したい場合

手続きは住民票関係だけでなく、電気・ガス・水道、学校、保険など、ほかにも多くあります。期限を一覧で管理したい方向けに、日付を入れるだけで期限日が出るExcelチェック表(BOOTH)を用意しています。詳しくは手続きの期限チェック表のページをご覧ください。

まとめ

  • 転出届は引っ越す前(事前)、転入届・転居届は住み始めた日から14日以内
  • マイナンバーカードは、転入届の提出後90日以内に継続利用手続き
  • 自動車は別に変更登録が必要。日数は国土交通省のポータルで確認
  • オンラインの受付時期など、細かい条件は自治体で異なる
