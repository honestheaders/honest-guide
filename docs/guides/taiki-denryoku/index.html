待機電力とは?家庭の電気に占める割合と、測り方・減らし方

更新日:2026-09-30

※この記事にはプロモーション(広告)が含まれます。商品リンクから購入されると、当サイトに報酬が入ることがあります。

電気代の明細を見ると、「何も使っていない時間の分」も入っているのだろうか、と気になることがあります。その正体が、待機電力です。この記事では、割合の数字を公的な情報で確認したうえで、測り方と減らし方の考え方を整理します。

待機電力とは

環境省の節電ページ(COOL CHOICE)では、待機電力を「使用していない場合にも電力が消費される待機時の消費電力」と説明しています。

もう一つ、関東電気保安協会のページでは、待機時を「家電製品のプラグをコンセントに差し込んだだけで作動していない状態」としています。この間に使われる電気は、表示、タイマー、リモコンの受信といった機能を保つためのものです。

どのくらいの割合なのか

資料によって数字が少し違います。

  • 環境省のページ:年間の家庭の消費電力量の約6%。「テレビの消費電力量とほぼ同じ割合」と書かれています。
  • 関東電気保安協会のページ(省エネルギーセンターの平成24年度調査を引用):1世帯あたり平均228kWh/年で、全体(4,432kWh/年・世帯)の5.1%。

調査の年や対象で数字が変わるため、「全体の5〜6%ほど」と受け取るのがよさそうです。どちらの数字も、家庭全体の平均です。ご自宅の家電の数や種類で、実際の値は変わります。

減らし方と、その効果の目安

関東電気保安協会のページには、次の2段階が紹介されています。

  1. 使わないときに、主電源スイッチをこまめにオフにする → 待機時消費電力量を約33%削減
  2. さらに、使わない機器のプラグを抜く → 約49%削減

環境省のページでも、プラグを抜くことと、こまめに主電源を切ることが対策として挙げられています。

自宅の待機電力を測るには

「うちの機器は実際どれくらい?」を知りたいときは、コンセントと家電のあいだにはさんで、消費電力(W)を表示する「ワットチェッカー」のような計測器があります。待機中の機器につないで数字を見れば、プラグを抜く価値があるかを、自分の家の機器で判断できます。

電気代への換算のしかたは、電気代の出し方にまとめています。

  • 楽天市場で「ワットチェッカー」を探す
  • 楽天市場で「スイッチ付き電源タップ」を探す

スイッチ付きの電源タップなら、まとめて電気を切る手間が減ります。

注意点(デメリット)

  • プラグを抜くと、時計や録画予約などの設定に影響が出る機器があります。環境省のページも、そうした機器には「表示OFF機能」の活用を挙げています。
  • 冷蔵庫のように、常に動いていることが前提の機器は、プラグを抜く対象ではありません。
  • 抜き差しが面倒になって続かないなら、無理をせず、主電源のオフだけにするのも一つの方法です。
  • ワットチェッカーやスイッチ付きタップは、買うお金がかかります。減らせる電気の量と、見比べてから決めてください。

まとめ

  • 待機電力は、公的な情報では家庭の電気の5〜6%ほど
  • 主電源オフで約33%、プラグを抜くと約49%減らせるとされる
  • 設定への影響や、抜いてはいけない機器に注意する
