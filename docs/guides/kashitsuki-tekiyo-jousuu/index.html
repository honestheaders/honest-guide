加湿器の「適用畳数」は何を表す?数字の見方と注意点

更新日:2026-09-30

※この記事にはプロモーション(広告)が含まれます。商品リンクから購入されると、当サイトに報酬が入ることがあります。

加湿器の箱には「木造和室〜8.5畳、プレハブ洋室〜14畳」のように書かれています。この数字は、何をもとにしているのでしょうか。

適用畳数は「水分を出す量」から決まる

一般社団法人 日本電機工業会(JEMA)の規格(JEM 1426)では、加湿器の適用床面積は、室温20℃、湿度30%の条件で、1時間にどれだけ水分を出せるか(例:500ml/h)をもとに決めることになっています。

つまり、適用畳数は、その加湿器が部屋を加湿できる力の目安です。

木造和室と洋室で数字が違う

適用床面積は、建物のタイプによって変わります。JEMAが定めた表に、木造和室とプレハブ洋室で別の数字が載っているためです。どちらの数字を見るかで、選ぶ機種が変わることがあります。

具体的な畳数は、各社のカタログや取扱説明書に、木造和室とプレハブ洋室に分けて書かれています。ご自宅がどちらに近いかを考えて、数字を見てください。

選ぶときの注意点(デメリット)

  • 適用畳数は「目安」です。住まいの造りや、暖房の使い方、部屋のドアの開け閉めで、実際の効き方は変わります。
  • 畳の大きさは地域で違います。詳しくは、1畳は何平米?畳・坪・平米の関係を見てください。
  • 数字ぎりぎりの機種を選ぶと、寒い日にはパワー不足を感じることがあります。ここは、余裕を見て考える人が多い部分です。

部屋の湿度を確かめるには

加湿器を買う前や、使い始めてから、実際の湿度を測る道具に、温湿度計があります。数字で見られると、加湿器が効いているかどうかが分かりやすくなります。

  • 楽天市場で「加湿器」を探す
  • 楽天市場で「温湿度計」を探す

まとめ

  • 適用畳数は、1時間に出せる水分の量から決まる目安
  • 木造和室とプレハブ洋室で、数字が違う
  • ぎりぎりを避けて、余裕を見て選ぶ
